## Liquid Glass 视觉重构计划（桌面 Web 优先）

### 研究结论（已完成的深入学习）
- **来源**：liquidglassdesign.com 指南 + 画廊组件预览图（iOS 26 菜单浅/深对照、下拉菜单、按钮概念、visionOS 桌面）、Mockflow 四层模型与透明度体系（关键内容 100%、辅助 70%、装饰 40%、氛围 20%）、liquid-glass-react / shuding SVG 滤镜两个实现参考。
- **核心配方**：①玻璃只用于控制层与浮层，正文/表格保持近实色；②玻璃的观感来自背景彩域（渐变背景是材质的"燃料"，必须保留且丰富）；③表面亮度沿左上光源渐变 + 外缘高光顶部更亮 + 底部暗缘出厚度；④同一工具组共享连续玻璃容器；⑤悬停 = 行内浮起小瓷砖而非变色；⑥主操作用实色（100% 不透明）；⑦深色模式玻璃染上环境色相；⑧网页真折射（feDisplacementMap）仅 Chromium 可靠 → 按需求书采用 CSS 分层近似，不引依赖。

### 现状
令牌系统、四层结构、三档玻璃、Segmented、Modal、无障碍层均已落地；渐变彩域环境已恢复进 CSS 但上次构建被打断、未验证。

### 实施步骤
1. **基线恢复**：跑上次被取消的构建 + 21 项测试 + audit；浏览器确认渐变恢复后浅/深色首页。
2. **材质精修**（index.css）：`.btn-ghost` 升级为轻玻璃瓷砖（sheen + 顶高光 + 0.5px 外缘 + hover 染 accent）；分段底座加 sheen 与浮起阴影；下拉悬停行改为行内浮起瓷砖；深色玻璃加轻微靛/紫色相；核对三级阴影层级。
3. **组件逐个落实**：侧栏选中项改浮起瓷砖底座（visionOS 式）；Combobox 行悬停瓷砖 + 分组发丝线 + 红色破坏项分隔线；计时卡作为视觉重心加强 sheen；其余卡片常规内容面；状态胶囊轻玻璃。
4. **交互状态核查**：悬停提亮、按下 0.98、浮层 0.97→1 展开、禁用态、键盘 focus-visible 全覆盖。
5. **验证**：对比度复测（≥4.5，彩色背景下重点核对）；reduced-transparency/@supports 实色降级生效；reduced-motion 降级。
6. **回归收尾**：21 测试/构建/audit=0；1440 桌面浅深色视觉核对 + 320px 溢出复查；更新 `docs/reviews/2026-09-13-code-review-ui-plan.md` 增补液态玻璃重构章节（来源、配方、组件清单、验收结果）。

### 明确不做
SVG 真折射滤镜（跨浏览器不稳定）；新增依赖；改动业务逻辑/路由/数据结构；手机端重构（仅保证不回归）。

### 验收
关闭模糊后布局仍成立；玻璃仅出现在控制层/浮层；材质、光源、圆角、动效节奏一致；深浅两模式均清晰；所有交互（搜索/筛选/计时/弹窗/主题切换/图表）真实可用。
