- **本地优先完整性**：删除关联进度的记录并勾选撤销时，路线进度精确回退（+1 创建 → 8/10；撤销 → 7/10），未出现双计或漏退。

- **状态还原**：`?q=复习&filter=<id>` 刷新后搜索框与筛选下拉均还原。
