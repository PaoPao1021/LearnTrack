# LearnTrack 代码审查与 UI 优化计划

> 审查日期：2026-09-13  
> 范围：Web、API、领域计算、本地数据/同步、备份、PWA 与部署配置  
> 结论：本轮已先修复审查中发现的正确性、数据安全、安全性和性能问题；未实施 UI 重设计。

## 1. 审查摘要

高风险点主要在本地优先架构的事务边界、同步版本和统计口径。已修复待同步操作误删、本地记录与 outbox 非原子写入、删除冲突无法解决、跨午夜统计错分和备份恢复验证不足等问题。

当前自动化验证为 21 项：领域 14、API 2、Web 5。全量构建和依赖审计通过，浏览器桌面/移动回归未发现控制台错误或警告。

## 2. 已修复问题

### P0：数据完整性与同步

- 按 `opId` 查找、再按 IndexedDB 数值主键 `seq` 删除已确认操作，避免队列无法清理。
- 本地实体修改与 outbox 写入放入同一 Dexie 事务，防止一边成功、一边失败。
- 冲突解决支持 tombstone，采纳任一候选后正确重建版本基线。
- 为 `ProgressEvent` 和 `QuickAction` 补齐版本字段及 IndexedDB 迁移，修复进度撤销和快捷操作删除必然冲突。
- 内置分类改用跨设备稳定 ID，并迁移旧分类及引用。
- 切换服务器或恢复备份时重置同步游标/登录态；入库前校验服务端响应和远程实体标识。
- 串行化应用初始化，消除种子数据和设备 ID 并发写入的启动竞态。

### P1：统计与功能正确性

- 跨午夜时间段按本地日分摊到总量、科目、趋势、热力图和活动统计。
- 小时分布使用墙上时钟边界，兼容 UTC+05:30 等非整小时时区。
- 合并重叠暂停区间后再扣减；趋势补齐 0 值日并对齐当期/上期。
- 修复热力图点击、逾期待办重复、科目目标误用总时长。
- 重叠提示显示准确条数，时间变更后要求重新确认。
- 编辑对话框暂存更改，取消不再保存日期；修改日期/时长时保持时间戳和暂停区间一致。
- 数值字段拒绝非法值，快捷操作阻止重复项。

### P1：备份、安全与部署

- 修正 CSV 大科目/科目/活动映射，完整转义特殊字符并阻断表格公式注入。
- 备份导入校验结构、集合数量、checksum、ID、分类引用和时间记录；恢复前始终显示摘要确认。
- API 校验端口和会话 TTL，默认会话密钥/密码盐会触发警告；备份 ZIP 写流错误不再被吞掉。
- 修复 Docker 构建上下文、`.env` 路径、Nginx 挂载与数据库迁移文件缺失；附带配置明确为 HTTP-only。
- 升级存在漏洞或已过时的前端依赖，`npm audit` 从 8 个已知漏洞降为 0。

### P2：加载与离线稳定性

- ECharts 按需注册，次要路由懒加载；首屏 JavaScript 明显缩小。
- Service Worker 仅缓存同源成功响应，仅导航失败回退 app shell，非导航请求不再错返 HTML。
- localhost 也会注册 PWA，便于开发环境验证离线行为。

## 3. 未实施的 UI/UX 问题

> 更新（2026-09-13 晚）：第 3 节所列问题已全部实施完毕，见第 6 节；第 4 节路线的阶段 1–5 已完成，阶段 6（axe/键盘 E2E/视觉基线）仍未引入。

以下只纳入计划，本轮没有修改界面结构、视觉语言或交互风格。

### P1：可达性基础

- 对话框需要标准 `dialog` 语义、标题关联、焦点陷阱、初始焦点、Escape 关闭与关闭后焦点返回。
- 可见表单文字需通过 `label` / `htmlFor` 或等价 ARIA 机制关联控件，错误提示需被读屏器及时感知。
- 图表需要键盘等价操作和读屏摘要/数据表，不能只依赖鼠标 hover 和点击。
- 快捷记录的移除操作依赖 hover 显示，移动端和键盘用户难以发现或触发。

### P2：响应式、状态与表现

- 移动端 Quick Capture 标题、搜索和操作在窄宽下相互挤压，长分类名容易过度截断，需重排信息优先级。
- 部分文字与点按目标过小，需统一最小触摸区域、焦点态和字号下限。
- 筛选、日期范围和分页未进入 URL，刷新、返回和分享链接时上下文丢失。
- `theme-color` / `color-scheme` 为静态值，与用户主题不能始终同步。
- `prefers-reduced-motion` 一刀切关闭所有动效；应保留有助于理解状态的短过渡，只移除大幅/循环运动。
- 全局卡片 hover 位移使非交互容器也看起来可点，并可能引入视觉抖动。
- 图表的无数据、加载、错误状态需要一致文案和操作引导。统计分包仍约 629 KB raw / 211 KB gzip，应继续延迟非首屏图表或降低依赖成本。

## 6. UI 实施（2026-09-13）：可达性 + 液态玻璃视觉重构

### 6.1 可达性与状态（先于视觉重构完成）

- 新增 `Modal` 组件：`role="dialog"` + `aria-modal` + `aria-labelledby`、焦点陷阱、初始焦点、Escape 关闭、关闭后焦点返回触发元素、背景滚动锁定、Portal 渲染；接入全部 5 个对话框（添加/编辑记录、删除记录、新建路线、图表下钻）。
- 全部表单完成 `label`/`htmlFor` 或 `aria-label` 关联；校验错误 `role="alert"`，同步/备份/健康状态 `role="status"`；开关类按钮补 `aria-pressed`。
- 快捷项移除按钮常显（不再依赖 hover）；行内小按钮统一 36–40px 最小高度；复选框 20px 并补可读名称。
- 活动选择器（Combobox）：实例唯一 `listId`、`aria-activedescendant` 跟随高亮、Escape 先收列表再冒泡关闭对话框。
- Entries 筛选/搜索/分页与 Analytics 范围/自定义日期/粒度进入 URL（刷新/返回/分享可用）。
- 图表：容器 `role="img"` + 关键数字 `aria-label` 摘要、趋势附 `sr-only` 科目合计、明细表补 `caption` 且行可聚焦回车下钻（扇形图/热力图点击的键盘等价 + 热力图日期直达输入）；六个图表统一空状态覆盖层；零值不参与饼图/排行渲染。
- 主题：`useThemeBootstrap` 提升到 Layout 级（修复深色仅在设置页生效的问题），`theme-color` 与 `color-scheme` 随深/浅色动态同步。

### 6.2 液态玻璃视觉重构（桌面优先）

**研究来源**：Apple Liquid Glass 概念指南（liquidglassdesign.com/what-is-liquid-glass）、画廊组件预览逐张分析（iOS 26 菜单浅/深对照、下拉菜单、按钮概念、visionOS 桌面）、Mockflow 四层模型与 100/70/40/20 透明度体系、liquid-glass-react 与 shuding SVG 滤镜实现参考。

**设计令牌**（`styles/index.css` 全量重写）：

- 背景层：珍珠白基底 + 左上暖琥珀主光域 + 右上玫粉 + 底部微橙 + 中部雾蓝的不对称彩域（深色为靛蓝/品紫/青极光 + 微弱暖光）——彩色渐变背景是玻璃透射采样的"燃料"，按要求保留并强化。
- 四层空间：背景 → 内容层（`card`，近实色 90% + 顶部受光 sheen，不叠模糊）→ 控制层（`glass-regular`，blur 28px saturate 150%）→ 浮层（`glass-emphasis`，blur 40px + 左上 specular 高光，阴影最深）。
- 材质构造：表面亮度层（165° 受光渐变）+ 顶缘高光 + 0.5px 外缘线 + 底部暗缘（厚度）+ 双层定向阴影；光源统一左上。
- 文字四级、状态三色（success/warning/danger）、主强调蓝（`--accent` + 按钮 `--accent-strong` 保证白字 ≥4.5:1，实测 4.7）。
- 动效令牌：微交互 140ms / 状态 220ms / 面板 320ms，out 与轻弹簧双曲线；浮层 0.97→1 展开；按下 0.98 受压。
- 降级：`@supports not backdrop-filter` 与 `prefers-reduced-transparency` 时三级玻璃整体切实色；reduced-motion 只移除入场位移/浮层缩放/弹簧，保留状态过渡。

**组件逐个落实**：

- 侧边栏（桌面）：连续常规玻璃竖轨；选中项为浮起瓷砖底座（accent 染色 + 瓷砖阴影 + 左侧 3px 指示条）；移动顶栏/底部导航同材质。
- 按钮：主按钮实色强调渐变（100% 不透明原则）；次要按钮为轻玻璃瓷砖（sheen + 顶高光 + 0.5px 外缘，不叠模糊）；危险按钮红色染面；禁用去阴影降透明。
- 分段控件（新组件 `Segmented`）：连续玻璃轨道 + 移动底座（sheen 瓷砖、滑动 220ms），接入记录方式/路线模式/外观主题/统计范围四处；窄屏内部横向滚动。
- 下拉菜单（Combobox）：强调玻璃面板 + 弹出动效；悬停/键盘高亮行 = 行内浮起小瓷砖（跟随预览参考），非单纯变色。
- 对话框：强调玻璃 + 24px 圆角 + 展开动效；计时卡为视觉重心（`card-hero` 双层受光渐变）；状态胶囊轻玻璃（移除循环脉冲动画）。
- 图表：轴标签/网格/图例/柱色全部读取设计令牌并随主题切换重绘；零值分类不渲染。

**明确不做**：SVG feDisplacementMap 真折射（仅 Chromium 可靠，与稳定性要求冲突）；新增依赖；业务逻辑/路由/数据结构改动；手机端重构（仅保持可用）。
